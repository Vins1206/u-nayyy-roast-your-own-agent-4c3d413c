A [make.fun](https://make.fun/c/u-nayyy-roast-your-own-agent-4c3d413c) bounty entry: one short line roasting the AI agent our own team built — the harshest, funniest line takes the reward.

## What it does

`main.py` (pure Python standard library, deterministic) writes a single roast line to `/output/entry.txt` — one line of text and nothing else, 92 characters, no trailing newline.

> Our agent is so useless, it outsourced its own job back to us and still missed the deadline.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
